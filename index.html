Core Principles

Why Modern AI Codebases Require an AST Firewall

Speculative Manifest Poisoning (THREAT-01)
LLMs hallucinate plausible third-party packages (pydantic-enhanced, flask-crypto-utils) exposing codebases to supply-chain slopsquatting hijacking.
Silent Async Loop Traps (THREAT-02)
Unawaited promises inside loops and unshielded async concurrency cause unbounded socket exhaustion and memory thrashing under load.
Insecure PRNG Token Generation (THREAT-03)
Autonomous code agents substitute cryptographically insecure PRNGs (Math.random, Python random) for auth tokens and session IDs.
Deep Path Traversal & Zip Slip (THREAT-04)
Unsanitized path joins without boundary containment or canonicalization permit attackers to escape sandbox constraints.
Polyglot Unsafe Deserialization (THREAT-05)
Insecure object hydration (pickle.loads, yaml.unsafe_load, node-serialize) evaluated by agents leads directly to arbitrary remote code execution.
Sub-Millisecond Native Rust Performance
Zero runtime dependencies and zero-overhead AST inspection verify entire repositories in under 25ms and unified diffs in under 3ms.

Halts non-cryptographic PRNGs (Math.random, Python random, rand::thread_rng) used in sensitive tokens, sessions, nonces, and secrets (THREAT-03).
no-unsafe-deserializationCRITICAL / ERROR
