THE PROBLEM

Why AI-Assisted Codebases Slowly Decay

Unfinished Placeholders & Silent Catches
Agents frequently leave behind todo stubs, unimplemented functions, or silent empty catch blocks that swallow critical production exceptions.
Phantom Imports & Ghost Packages
LLMs hallucinate package exports that do not exist (e.g. useLocalStorage from react) and import third-party libraries not listed in package.json.
Hardcoded Secrets & Unsafe Dynamic Eval
Agents accidentally paste API keys, private certificates, or unsafe eval/pickle calls directly into source files instead of using environment variables.

INSTALLATION & INTEGRATION GUIDES

Get Started In Under 60 Seconds

Standalone Binary

Download and run directly with zero dependencies:

# Windows
curl -LO https://github.com/avelone123123/slopguard/releases/download/v1.0.0/slopguard-v1.0.0-windows-x64.exe
.\slopguard-v1.0.0-windows-x64.exe

Cargo Install

Build and install to your user bin directory:

cargo install slopguard
slopguard monitor

Cursor MCP Setup

Add to ~/.cursor/mcp.json for real-time agent interception:

{
  "mcpServers": {
    "slopguard": {
      "command": "slopguard",
      "args": ["mcp"]
    }
  }
}

Claude Code

Connect the MCP stdio protocol directly:

claude mcp add slopguard slopguard mcp

Git Pre-Commit Hook

Block slop from entering your repository commits:

slopguard hook install

GitHub Actions CI

Generate your workflow in one second:

slopguard ci
