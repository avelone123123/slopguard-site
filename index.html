Core Principles

Why AI Codebases Require an AST Firewall

Unfinished Placeholders & Silent Catches
AI coding models frequently leave todo stubs, unimplemented functions, or silent empty catch blocks that swallow exceptions in production.
Phantom Imports & Ghost Packages
LLMs hallucinate package exports that do not exist (e.g. useLocalStorage from react) and import third-party libraries not listed in package.json.
Hardcoded Secrets & Unsafe Dynamic Eval
Agents accidentally paste live API keys, tokens, private keys, or unsafe eval() / pickle.loads() calls directly into committed source files.

Installation & Setup

Standalone Binary (v1.7.0)

Native precompiled executables:

# Windows x64:
curl -LO https://github.com/avelone123123/slopguard/releases/download/v1.7.0/slopguard-v1.7.0-windows-x64.exe
# Linux x64:
curl -LO https://github.com/avelone123123/slopguard/releases/download/v1.7.0/slopguard-v1.7.0-linux-x64
# macOS arm64:
curl -LO https://github.com/avelone123123/slopguard/releases/download/v1.7.0/slopguard-v1.7.0-macos-arm64

Cargo Install

Build and install to your user bin directory:

cargo install slopguard
slopguard monitor

Cursor MCP Setup

Add to ~/.cursor/mcp.json for live interception:

{
  "mcpServers": {
    "slopguard": {
      "command": "slopguard",
      "args": ["mcp"]
    }
  }
}

Claude Code

Connect the stdio MCP server:

claude mcp add slopguard slopguard mcp

Git Pre-Commit Hook

Block unverified slop from repository commits:

slopguard hook install

GitHub Actions CI

Generate CI workflow file automatically:

slopguard ci
