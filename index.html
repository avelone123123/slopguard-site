Core Principles

Why Modern AI Codebases Require an AST Firewall

Speculative Manifest Poisoning (THREAT-01)
LLMs hallucinate plausible third-party packages (pydantic-enhanced, flask-crypto-utils) exposing codebases to supply-chain slopsquatting hijacking.
Silent Async Loop Traps (THREAT-02)
Unawaited promises inside loops and unshielded async concurrency cause unbounded socket exhaustion and memory thrashing under load.
Polymorphic Deserialization (THREAT-03)
Arbitrary gadget execution via yaml.Loader, pickle.loads, marshal.loads, and Java ObjectInputStream evaluated by agents.
Broken Cryptographic Entropy (THREAT-04)
Weak pseudo-random number generators (Math.random, random.random, static seeds) used in authentication, salts, and session tokens.
Evasive Path Traversal (THREAT-05)
Unconstrained file resolution (path.join, path.resolve) without canonical root boundary verification permitting sandbox escape.
Sub-Millisecond Native Rust Performance
Zero runtime dependencies and zero-overhead AST inspection verify entire repositories in under 25ms and unified diffs in under 3ms.
