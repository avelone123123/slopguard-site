Architecture

Why AI Codebases Require an AST Firewall

Unfinished Placeholders & Silent Catches
AI coding agents frequently leave todo!(), unimplemented stubs, or empty catch (e) {} blocks that silently swallow exceptions at runtime.
Phantom Imports & Ghost Packages
Models invent non-existent package exports (e.g. useLocalStorage from react) and import third-party packages missing from package.json.
Hardcoded Secrets & Unsafe Dynamic Eval
Agents mistakenly paste live API keys, tokens, private keys, or unsafe eval() / pickle.loads() calls directly into committed source files.

no-ghost-dependenciesERROR

no-ghost-env-varsERROR
Flags environment variables referenced in code but missing from .env.example templates.
no-type-safety-degradationERROR
Halts compiler suppression escapes like @ts-ignore, : any, and double casts.
no-mock-hallucinationsERROR
Blocks hardcoded placeholder URLs (jsonplaceholder, test emails) left in production files.

Installation & Setup

Standalone Binary

Windows x64 executable with zero dependencies:

curl -LO https://github.com/avelone123123/slopguard/releases/download/v1.0.0/slopguard-v1.0.0-windows-x64.exe
.\slopguard-v1.0.0-windows-x64.exe

Cargo Install

Build and install to your user bin directory:

cargo install slopguard
slopguard monitor

Cursor MCP Setup

Add to ~/.cursor/mcp.json for live interception:

{
  "mcpServers": {
    "slopguard": {
      "command": "slopguard",
      "args": ["mcp"]
    }
  }
}

Claude Code

Connect the stdio MCP server:

claude mcp add slopguard slopguard mcp

Git Pre-Commit Hook

Block unverified slop from repository commits:

slopguard hook install

GitHub Actions CI

Generate CI workflow file automatically:

slopguard ci
